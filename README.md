# Expense Tracker

## Overview

This is a simple expense tracker project that allows you to add, list, update, delete, and generate reports for your expenses.

## Features

1. **Add Expense**: Add a new expense with an amount and description.
2. **List Expenses**: Display all recorded expenses.
3. **Update Expense**: Modify an existing expense's amount and description.
4. **Delete Expense**: Remove an expense from the list.
5. **Generate Total Expense Report**: Display the total amount of all expenses.
